# RAPID

**Request-Aware Parent-Set Inference for Recovering Executable Tool Workflows in Large Language Model Agents**

## Overview

RAPID is a research project focused on recovering executable tool dependency graphs in large language model agents through request-aware parent-set inference.

The approach models direct dependencies among candidate tools using contextualized edge representations, parent-set scoring, request-conditioned cardinality estimation, and globally consistent graph inference.
